# Project Setup

## Goal

Create the initial React application using Vite.

## Why React?

React allows a website to be broken into reusable components instead of one large HTML page.

## Why Vite?

Vite is a modern frontend build tool that provides a fast development server, quick builds, and Hot Module Replacement (HMR), making development faster than older tools like Create React App.

## Commands Used

```bash
npm create vite@latest . -- --template react
npm install
npm run dev
```

## What I Learned

- Vite can create a project in the current directory using `.`
- `npm install` downloads the project's dependencies
- `npm run dev` starts the development server
